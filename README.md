# python1:
A hands-on Python learning repository containing practical Jupyter notebooks, scripts, exercises, mini projects, and concepts covering Python fundamentals, data structures, OOP, advanced Python, and real-world applications.

The goal of this repository is to move from Python basics → data structures → functions → OOP → advanced Python → libraries → practical projects.

⚙️ Installation
bash
# Clone the repository
git clone https://github.com/USERNAME/Python-Course.git
cd Python-Course

# Create a virtual environment
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Launch Jupyter
jupyter notebook
